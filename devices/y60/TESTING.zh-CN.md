# 金世纪 Y60 / Coolpad CP23NV3 实机测试包

这是首次硬件测试包，不是已完成实机验收的正式版本。目标平台为 UMS9620、
CP23NV3 / 3292SG，已比对 CP21.20240108.0S.GCY 与 CP21.20240304.1S.GCY。
已核实的屏幕组合为 ILI9488 320×480 + TLSC6540；其他批次不能视为已验证。

远程反馈：短信、振动、充电、显示/触摸/亮度和通话听筒基本正常。
本轮针对“扬声器仍无声、麦克风收音小”，按原厂模块修正AW87xxx功放回调，
补齐听筒/免提/录音各自的原厂麦克风增益。请复测媒体、提示音、免提声音和
双方通话音量，再确认听筒及挂断后的媒体播放正常；蓝牙仍需另行实测。

本轮同时补齐升级时的写入进度、写后回读阶段提示，以及本机音频 XML 的保留。
升级会写入完整系统镜像，再回读校验，耗时不能按压缩包大小估算；进度输出不代表
已完成写入。如果旧版升级已经丢失本机音频 XML，单纯再次升级不能恢复缺失文件，
需返回本机 Android，使用安装器“重装已有内置分区”重新提取本机固件及音频参数。

## 安装与回退

1. 解压完整 ZIP，阅读本指南。Windows 运行根目录 `OpenWrt-Installer.exe`；
   Android 控制端安装根目录 `OpenWrt-Tools.apk`；Apple Silicon 使用根目录 App。
   也可以用 Python 入口。不要单独找一份 boot 镜像替代完整安装流程。
2. Y60 先进入 Android，启用 USB 调试并给予 root。首次试机优先用 TF 卡安装，
   保留安装器在控制端保存的备份和安装记录。TF 安装会清除所选 TF 分区。
   本包不绕过 AVB；Android 的 verifiedbootstate 须符合安装器现有的启动链检查。
3. 安装器读取本机当前 Android 槽并写入另一个槽，按本机内容同步 BSP、DTBO、
   vendor_boot；不假定 Android 一定在 A。不要手动混刷其他机型的 BSP/触摸固件。
4. 固件、蓝牙地址、音频参数和 NV 均从正在安装的这台机器提取；包内没有
   备份机器的 IMEI、NV、Wi-Fi 密码或运营商配置。首次导入需要时间。
5. 内置分区安装仍可使用，但 Y60 尚未实测。原厂 userdata 是 FBE + metadata
   加密 F2FS；在线无损缩容是否可用由设备探测决定。若需清除数据，必须另外确认，
   不要把同意安装理解为同意清空 Android。
6. 临时启动失败时，可按现有 A/B 回退机制强制重启回 Android；保留错误画面和
   安装日志。不要连续重新安装或格式化来排错。使用安装器和匹配备份恢复启动链。

## 第一次开机

- 默认管理地址 `192.168.9.1`，SSH 用户 `root`，初始密码 `root`。
  热点默认 `Y60-OpenWrt`，密码以安装时输入/生成的值为准。
- 核对屏幕、触摸、实体键、息屏亮屏；不应出现诊断色块。
- 用一张可联网 SIM 测试上网，再测试切卡、短信、电话的听筒/外放和麦克风。
- 测试通知提示音、媒体播放及音量从小到大；原厂最大媒体数字增益为 34，
  不继承 M8 的共用扬声器和 5 档听筒限制。蓝牙声音需真实耳机确认。
- 测试 USB 网卡、普通 OTG；再单独测试“主机＋外部供电”。角色控制已接入，
  是否能边充电边 OTG 尚无 Y60 实机结论，不能由其他机型测试替代。
- 使用正常充电器观察充电电流、温度、电量增长、停充和回充。电池 DT 为
  3050mAh、4340mV，不能按 M8/K1 参数或百分比强制校准。低电量关机需后续确认。
- 调压默认 0mV。先完成默认电压稳定性测试，再小步调整；SMC 接口已静态核实，
  但尚无 Y60 运行时电压或稳定性验收。

## 出错时收集

保存安装器“导出日志”，SSH 可用时保存 `uname -a`、`dmesg`、`logread`、
`cat /proc/cmdline`（分享前隐藏序列号等身份）、`ls /sys/class/udc`、
`cat /proc/asound/cards`。不要分享原始 NV 或安装备份中的个人身份文件。

本轮新增只读诊断命令，可在网页终端或SSH运行：

```sh
/usr/libexec/y60-collect-audio >/tmp/y60-audio.txt 2>&1
```

它只读取声卡、启动状态、生效路由和蓝牙/音频错误，不改mixer、GPIO或NV。
如果仍无声，请保留这份文件供远程分析，不必提供整机备份。

本包已做源码、驱动回调、模块配套、干净根文件系统及 ZIP 完整性检查；这些均是
离线验证，不表示上述硬件功能已经通过。请先反馈启动/屏幕/触摸/USB，再逐项测试。
