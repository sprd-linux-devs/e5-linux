# Y60：CPU 调压的原厂固件依据

2026-11-01，仅完成离线核验，未测量硬件电压、温度或稳定范围。

两套 CP23NV3 备份的 A/B 各自一致，完整 1 MiB SML 分区 SHA256 分别为：

- CP21.20240108.0S.GCY：`7755b6ae0282e308eab179710401bfc2a16f86e3658936cdf79ee581fda0a3a9`
- CP21.20240304.1S.GCY：`355cf12fa6fa336c013ac94ace426bceb094ed5c27b95995e7ba1628c6d0348b`

以已核验的 K1 原厂 B 槽
`efc2e6cf3a83a1dbbedecbea12673a7320520632b7b3f59c9072276f9b24d5eb` 作比较：
三份镜像的 DHTB 头均声明 payload 长 0x224f0，位于文件 `[0x200,0x226f0)`。
各自的 payload SHA256 均与头部 `[8,40)` 一致，**整个 payload 字节完全相同**，
不是只比较名称或少量特征。完整镜像差异从 payload 以外开始；不需要猜测
那些签名／附加数据的含义来认定 DVFS 实现一致。

因此 [K1 已核验的 SMC 分发、三域参数、CPU/SRAM 配对表及 3.125 mV selector
计算](../k1/CPU-POWER.zh-CN.md)同样存在于这两版 Y60 payload 中：
`0x8200060b` 是一次性 DVFS_INIT，三个偏移字节位于 bits 8～31；
每字节 bit7 表示负号，低七位表示 mV 幅度。没有新增 SMC 操作或另一套调压逻辑。

`verify-sml.py` 可从本机原备份复现完整镜像身份、DHTB 校验及整个 payload 比较。
公共 CPU 后端只增加两份完整镜像哈希，仍要求 UMS9620 和两槽同一份已核验固件。
混用两版 Y60、混用 K1 或任何未知／被修改的镜像都不允许非零偏移。
不写入 SML，不同步 BSP，不改原厂 OPP／电池表，不直接操作 PMIC。

沿用公共的 −50～+25 mV、3.125 mV 步进、默认零偏移、下次开机应用、异常启动回退
和关机充电使用原厂电压。接口一致并不保证每颗 Y60 芯片都能承受任意降压档位；
目前没有任何 Y60 实机的调压效果、全档位稳定性或续航结论。
