# 流量池按查看卡槽更新

E5 保留独立的双卡账本和 `view-sim0.json` / `view-sim1.json` 布局。
原生看板的未指定卡槽请求改为从当前实际数据卡选择对应文件，避免使用
切卡前残留的共享 `view.json`；无法确定数据卡或缺失所选账本时显示不可用。
主页的套餐剩余标题同步展示该卡套餐名称，统计快照补齐对应名称字段。

流量池原来刷新仅重绘用量，不更新已载入的套餐表单。现在刷新同时同步
套餐名称、额度、周期和计量方式；同卡未保存的输入保留，查看不同卡时完整
换入它的配置。读取明确绑定卡槽，迟到响应不能覆盖另一卡；保存和清空绑定
确认时的原表单卡槽，不随弹窗期间的查看选择漂移。

没有更改物理卡源、上网卡、流量账本格式或旧记录。不复制 MU300 的存储路径。

验证：原生 ucode 看板 11 项测试、真实私有 ubus 流量服务 46 项检查通过；
`openwrt/tests/traffic-slot-browser.py` 在手机与桌面布局验证分卡套餐／用量、
未保存编辑、乱序返回、保存及清空的不可变卡槽。均为隔离离线测试。
